# Ejercicios de Flexbox

Resuelve los ejercicios en orden, siguiendo las referencias de cada carpeta.

## Cómo trabajar

1. Abre el archivo **index.html** del ejercicio con Live Server.
2. Completa su hoja **style.css**, que ya está enlazada desde el HTML.
3. Modifica la estructura HTML cuando el enunciado lo indique.
4. Compara el resultado con la referencia y revisa la autoevaluación.

Cada HTML utiliza la hoja de estilos de su propia carpeta:

```html
<link rel="stylesheet" href="style.css">
```
